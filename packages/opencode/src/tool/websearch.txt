- Search the web using Parallel AI (primary) with Exa as fallback — performs real-time web searches and returns LLM-optimized excerpts from the most relevant sources
- Provides up-to-date information for current events and recent data
- Supports configurable result counts and excerpt length
- Use this tool for accessing information beyond knowledge cutoff
- Searches are performed automatically within a single API call

Usage notes:
  - Default provider is Parallel AI when PARALLEL_API_KEY is set; otherwise falls back to Exa
  - `livecrawl` and `type` parameters only apply to the Exa fallback provider
  - `numResults` and `contextMaxCharacters` apply to both providers

The current year is {{year}}. You MUST use this year when searching for recent information or current events
- Example: If the current year is 2026 and the user asks for "latest AI news", search for "AI news 2026", NOT "AI news 2025"
