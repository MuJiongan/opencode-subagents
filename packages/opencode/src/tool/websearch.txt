- Search the web using Parallel AI - performs real-time web searches and returns ranked URLs with relevant excerpts
- Provides up-to-date information for current events and recent data
- Use this tool for accessing information beyond the knowledge cutoff
- Searches are performed automatically within a single API call

Usage notes:
  - Pass a concise `query` with concrete keywords. Optionally supply an `objective` describing what you want to learn from the results when the query alone is ambiguous.
  - Search modes: 'fast' (default, low latency), 'base' (balanced), 'pro' (higher quality, slower)
  - `numResults` is an upper bound, not a guaranteed count
  - `contextMaxCharacters` caps the size of each returned excerpt and is tuned for LLM context windows

The current year is {{year}}. You MUST use this year when searching for recent information or current events
- Example: If the current year is 2026 and the user asks for "latest AI news", search for "AI news 2026", NOT "AI news 2025"
